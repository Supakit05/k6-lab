# k6-lab
งาน Lab การทดสอบประสิทธิภาพด้วย Grafana K6 (ITDS362)
Files
- RESULTS.md — ผลการทดสอบ Part 0, ตาราง Part A และคำตอบ Part B
- 01-first-test.js, 04-pizza-api.js, 05-no-token.js, 06-thresholds.js, 07-requirement.js, 08-bug-hunt.js, explore.js - สคริปต์ Part 0
- journey.js, a1-smoke.js, a2-average.js, a3-stress.js, a4-spike.js, a5-soak.js - สคริปต์ Part A
- reports/ - รายงาน HTML ของ A2, A3, A4 และ A5
Run
ใช้คำสั่ง k6 run <ชื่อไฟล์.js> ใน Terminal ที่เปิดอยู่ในโฟลเดอร์ k6-lab และดูผลการทดสอบใน RESULTS.md
